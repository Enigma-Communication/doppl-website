# V1.1 — DOPPL TEMP WEBSITE

Company website for DOPPL, a generative AI production studio.

- Responsive one-page layout with Studio, How we work, Capabilities and Contact.
- Editorial Enigma headings, Favorit Mono copy and alternating black and off-white modules.
- Looping opening film and transparent animated mascot, with Safari and WebM formats.
- Four expandable capability cards in a two-column desktop grid, stacked on mobile.
- Centralised website copy and an optional Word copy handoff utility.
- Password-protected Cloudflare Worker hosting, private R2 assets, verified uploads and video streaming support.
- Source code, original media, fonts, dependency lockfile and setup documentation.

Built with Next.js 16, React 19, TypeScript, custom CSS and Motion. Use Node.js 22, run `npm ci`, then `npm run dev`. Local development opens at `http://127.0.0.1:3000` and requires no production credentials.

The original V1 release remains available under `v1.0.0`.
